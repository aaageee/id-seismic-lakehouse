How the numbers are produced
  • Ingest splits the window into 31-day requests, writes raw GeoJSON per ingest day, and merges retries by event id.
  • Staging explodes the GeoJSON feature list, keeps the latest USGS revision and flags invalid rows into a quarantine model.
  • Intermediate assigns each event to the nearest provincial capital (haversine) and converts UTC to WIB / WITA / WIT.
  • Energy uses the Gutenberg–Richter magnitude–energy relation: log10(E) = 4.8 + 1.5M, reported in tons of TNT.
  • b-value is a least-squares fit of log10(N≥M) on M, using events at or above the completeness magnitude Mc.
Source: USGS FDSN event API (public domain). Not an official early-warning product. Python · DuckDB · dbt · GitHub Actions
